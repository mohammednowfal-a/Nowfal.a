## 🚀 How to Open & Run in VS Code

### Step 1 — Open the folder
1. Open **VS Code**
2. Go to `File → Open Folder`
3. Select the `moringaleaf-vscode` folder

### Step 2 — Install recommended extensions
When VS Code opens, it will prompt:
> *"Do you want to install the recommended extensions?"*

Click **Install All**. The key one is **Live Server** by Ritwick Dey.

### Step 3 — Launch with Live Server
1. Right-click on `index.html` in the Explorer panel
2. Select **"Open with Live Server"**
3. Your browser opens at `http://127.0.0.1:5500`
4. Every save auto-refreshes the browser ✨

## 🌐 How to Deploy (Go Live)

### Option A — Netlify (Free, Easiest)
1. Go to [netlify.com/drop](https://netlify.com/drop)
2. Drag and drop `index.html`
3. Your site is live in seconds with a free URL

### Option B — cPanel / Shared Hosting
1. Log in to your hosting control panel
2. Open **File Manager → public_html**
3. Upload `index.html`
4. Visit your domain — done!

### Option C — Vercel
1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → Import project
3. Connect your GitHub repo → Deploy
